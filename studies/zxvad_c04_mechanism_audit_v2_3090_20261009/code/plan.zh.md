每个面积和概率组合都完整包含以下六组：

| 方式 | 历史输入干预 | 作用 |
|---|---|---|
| PHOTO | 同局部框的亮度gain=.6–1.4/offset=±.2 | 常规corruption-to-clean恢复控制，非正常几何增强 |
| NOISE | 同局部框、四帧同一加性高斯噪声（σ=.2） | 随机局部干扰恢复控制 |
| SELF | 取recipient首帧自身内容，沿同轨迹粘贴 | 同源编辑痕迹控制；不能假定是真正常事件 |
| STATIC | 同donor内容、同面积，在同位置连续插入 | 无运动控制 |
| MOVE | 同donor、固定面积，位置r+tδ连续移动 | 主要时序干预候选，δ不超过4px/frame |
| SHUFFLE | 同MOVE的四个位置与内容，以[0,2,1,3]重排 | 关键时序顺序控制；禁止重新抽位置 |

强度网格仅为预声明的成组机制稳健性检查；每档都保留所有控制，不根据目标成绩选择p、面积或速度。每次输入干预只替换原四帧输入，原干净未来Y不变；模型仍一次前向，避免多算一次G导致算力混杂。

训练前冻结：源码/协议、297/33名单、训练/验证recipient+donor计划、目标标签与计分帧7056/1962/15240、同卡队列。所有32项完成最终5000step和源验证后才统一评测目标。源诊断包括同未来时刻Y/P×未粘贴/粘贴2×2、正常未来误差、复制末帧参考、历史时间依赖、合成未来残差；它们不能替代跨域性能。

读出保持主指标为逐视频min-max负PSNR的pooled frame AUROC。额外读出在同一冻结模型上进行，不另训练：NC-only、NC预测/真实差值、8×8局部残差上尾10%、源域median/IQR校准的PSNR+0.25NC，以及不做当前视频归一化的固定标尺版本。参数全部预定，N.eval并验证BN统计不变；不进行目标更新或跨视频累计适配。所有读出全数保留，不用最高目标AUROC反向选方案。

源验证使用训练之外的转向轨迹（位移上限6px/frame），而非训练中的直线轨迹。源域继续候选仅按预声明的源诊断确定，并在目标评测前留下选择记录；目标结果保持开发集比较口径，不能重新称blind。单种子、合成机制和固定c04差异均不支持稳定提升/首创/SOTA声明。

预算：32次5000step，16次/卡；按原约30分钟训练/项为8小时双卡墙钟训练，再加源验证和评测。已审核原B实际约23.5分钟/项，合并估计约8–10小时墙钟、约16–20 GPU小时，实际以日志为准。无截止时间、不自动无限追加。占用的卡等待空闲，不停止其他任务。
