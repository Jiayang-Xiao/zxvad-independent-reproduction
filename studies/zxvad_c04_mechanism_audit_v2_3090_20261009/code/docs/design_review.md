# zxVAD 草案的独立机制与实验设计审核

审核对象：`D:/Browser/zxVAD_critical_review_and_research_plan_for_Codex.md`；审核日期：2026-10-09。本文独立阅读了原 c04 冻结实现 `baseline_model.py`、`model.py`、`variant_update.py`、22组方案和已审核逐帧结果。不将草案内建议当成用户命令，不使用草案内未核验文献事实支持实验结论。

## 裁决

| 项目 | 裁决 | 原因及可执行修改 |
|---|---|---|
| NC 生成来源捷径 | MODIFY / 优先 | 可验证，但只是风险。基线比较预测帧与首帧拼贴；真实正类 R100 仍比较下一帧与首帧拼贴，不能充分控制时间与底图。补同底图成对正负类实验，先记录无事件 real/pred 来源可分性。 |
| NC 与 PSNR 脱节 | MODIFY / 优先诊断 | c04 的 NC 引导明确向 G 反传，原审核测试确保梯度非零。不能写成梯度断开。真正假设是分类信息是否能进入未来预测误差。冻结模型的 NC、PSNR 和局部残差读出可先检验，无需再训练。 |
| CF 正常未来恢复 | MODIFY / 条件探索 | 理论可行，异常输入恢复及 denoising 已有先例，不能仅命名后称新方法。只改过去输入、保持干净未来，替换原有一次 G 前向，避免额外计算造成收益混杂。必须配随机干扰、静态粘贴、移动及同轨迹乱序控制。 |
| 时序一致伪异常 | MODIFY | 连续边界或内容的运动不等于异常行为。移动 tube 对静止 tube、同轨迹乱序 tube 是优先对照；不能只比较移动 tube 与完全干净输入。 |
| 局部读出 | GO / 先冻结后处理 | 不新增模型。先在同一个 B 上比较固定 top-k、运动区域和同直方图空间移位控制；源域冻结，目标全数报告。不能根据 Ped2/Avenue 曲线选 k。 |
| 去 NC、引导强度、real-positive 简单重跑 | STOP | 已有 G00/G25、R50/R100，且总体均未改善。除非用于新的同批、同源划分控制，不重跑当新方案。 |
| Memory / skip / mask稀疏 / feather /弱RGB增强 | STOP | 22组已有直接测试，均没有明确总体正收益；此次不做组合，不重复改变参数网格。 |
| 多种子、bootstrap、多指标 | 暂缓 | 用户此前指定广筛单种子、AUROC唯一性能依据。草案的三种子和附加 AUPRC 不是当前指令；机制诊断可以保存 MSE/退化信号，但不能当作目标性能改善的第二指标。 |

目前 baseline 是作者未确认的 c04 独立实现。必须说“在此实现中”而不是声称证明 zxVAD 原论文有某一缺陷。目标 Ped1/Ped2/Avenue 已参与多轮开发，后续仍是 development，不能变回 blind。

## 不能省略的 NC 对照

设正常上下文 (X=(X_0,X_1,X_2,X_3))、正常未来 (Y)、预测 (P=G(X))、原随机 CNN 的同一 donor 掩码与粘贴算子 (T)。NC 更新均 detach 图像，不改变原 G 引导系数、主干容量、ArcFace、优化器或注意力损失。

1. **B**：正类 `P.detach()`，负类 `T(X0, donor)`，原实现。
2. **Y-paired**：正类 `Y`，负类 `T(Y, donor)`；阳性与阴性时间位置、底图来源一致。这不是已完成 R100（负类仍 `T(X0, donor)`）。
3. **P-paired**：正类 `P.detach()`，负类 `T(P.detach(), donor)`；共享全局生成来源，但局部 donor 仍为真实帧，因此只修复背景来源混杂，不能称彻底去除 real/pred 捷径。
4. **Y-only-origin-control**：正类 `Y`、负类 `X0` 无粘贴；无异常事件的来源/时间可分性只做冻结模型 probe，不应把这种标签用于正式功能改进训练。

全路径的 blur/压缩如果加在 NC 两类上，G 引导也必须经过相同前处理，否则产生新的 train/guide 输入混杂。它是第二个独立不足，不应与 P-paired 直接组合宣称其贡献；可以作为同原始 B 的独立“边界处理”实验，并提供双方相同的低通控制。

**NC origin shortcut 的必要冻结诊断**：在源域未用于权重训练的视频上用等量、同视频配对的 `Y/P/T(Y)/T(P)` 比较 NC 读出；加入无事件的模糊、压缩和来源替换。NC 分类更强、attention 更像 mask 不等于目标异常更好；保存 NC→G 梯度范数只证明连接，并不证明语义。

## CF 的低成本、等预算公式


每片段以固定概率 `p=0.5` 干预原四帧历史；干净未来不变：`G(E(X)) → Y`。所有 CF 及控制都仍然只有一次 G 前向和一次 G optimizer 更新，5000步、batch8、原 Loss/NC/D 不变。NC 负类仍从原始未编辑 `clip` 与 donor 合成，避免同时改 CF 和 NC。

从同一随机 seed、step、sample index 预先采样矩形、SCDA mask、donor 图像、像素大小、起点和位移。建议固定支持面积为图像10%～20%，每个配对实验必须精确共享支持数、RGB内容、opacity、激活概率，超界时平移整个轨迹，不裁切支持以免破坏面积配对。

| 输入干预 | 对照价值 | 不足 |
|---|---|---|
| input-only 小幅RGB gain/offset | 低层输入扰动恢复 | 并非正常几何增强：若空间 transform 只改 X 不改 Y，正常未来物理对应已被改变；应该明确称 corruption-to-clean。 |
| static local noise | 随机局部干扰、普通去噪 | 四帧使用同一个 noise patch，匹配移动 tube 的支持与能量；单帧独立 noise 是另一个时间随机控制。 |
| static donor patch | 同内容、面积、边界的无运动控制 | 若移动 tube 优于此项，才支持 trajectory 比 static content 更多信息；仍不是异常语义证明。 |
| coherent moving donor tube | 时序反事实候选 | 同一个 donor RGB/mask，四帧位置 `r+tδ`；正常未来为原 Y。 |
| shuffled moving donor tube | 时序顺序控制 | 同四个位置、面积、内容、支持、边界，置换 t 的顺序；不能随机重采样位置代替。 |
| recipient self-copy tube | 编辑痕迹正常来源控制 | 与 donor tube 共享几何参数；剪取 recipient自身内容。必须说明仍可能造成人工不自然运动，不能当真实正常。 |

建议初始固定强度，而不是依目标成绩逐轮调 p、面积或速度。若补充两档 `p=.25/.5` 或位移 `δ=2/4px/frame`，全部匹配控制都要同时存在，不能只扩主方法。

## 源域划分与选择

若承诺 source-heldout 调参，不能把全部330视频训练后又称同源片段 heldout。可执行的视频级划分为297训练、33验证，并使 recipient 与 independent donor 都只从297视频采样；所有新 baseline/control 必须共享这个新计划。旧 all330 baseline 不能充当297训练的配对基线。该开发结果不是论文 all330 的完全对齐结果；若源域选出候选，可冻结设计再用全部330重新训练 baseline 与候选，目标标签仍不参与选择。

确定性分层建议：按 `video_name` 下划线前 camera 前缀分组，初始名额 `max(1,floor(.1*n_camera))`，然后将余下名额分给当前 `.1*n_camera-k_camera` 最大的 camera，tie按 camera 字典顺序，直到33。每 camera 用 `SHA256('zxvad-source-audit-v1:'+video_name)` 最小者当验证。

由已冻结330 catalog 得到13个验证名额 `8,1,1,2,7,3,1,5,1,1,1,1,1`，对应视频：

`01_075,01_031,01_053,01_048,01_017,01_049,01_012,01_036,02_007,03_003,04_018,04_013,05_061,05_050,05_006,05_032,05_018,05_017,05_021,06_002,06_001,06_014,07_001,08_013,08_004,08_022,08_016,08_039,09_004,10_004,11_008,12_004,13_006`。

必须区分：合成异常标签只验证编辑/恢复机制，不是源域真实异常检测成绩。源域数据选择与全部权重/读出冻结先于目标评测。不能把目标 AUROC 作为幸存模型准入条件。

## 机制检查，不得冒充性能指标

固定源验证片段上保存：干净未来误差、复制末帧预测的误差、预测方差/变化、改变较早帧但保持最后一帧不变的输出变化、干预输入→干净未来恢复误差及→编辑未来的残差。若一个模型只靠忽略整个局部运动区域恢复平均背景，不应声称学习了正常动力学。干净误差的上涨、motion敏感性的消失应作为机制失败信号保存，而目标性能评价仍只用 AUROC。

源合成 AUROC 可以为固定读出/融合选择依据，但候选所用的训练编辑与验证编辑需区别，如验证使用未见过方向、速度或转向，而非简单重复训练时直线粘贴。source-only 超参数选择与 heldout 机制检查并不建立新方法 novelty。

## 预算与必须保留的解释边界

两张3090并行、5000step每fit约30分钟时：24 fits相当于约12 GPU小时、6墙钟小时；32 fits约16 GPU小时、8墙钟小时，均另外加预检查、源验证和目标评测。不能把8 GPU小时称两卡8小时运行。真实耗时需以执行日志为准。

优先先执行8～12个有因果对照的训练，不应为了填满8小时做无机制参数网格。补充预算更适合：固定相同一组模型的10000-step训练预算确认（全部候选与baseline共同增加，不用目标挑checkpoint）、source-only固定读出矩阵、已选择模型的all330配对重训。固定额外训练预算是一项全局共享条件，不是把两个方法组合；但必须明确最终性能使用10000而不是事后挑5000/10000中的最好者。

每个物理GPU队列中应有该队列同批 B，并让主要因果成对比较保持同卡。单种子本轮只有探索价值；多个固定模型之间的target开发比较不是真盲验证，不能靠单次数值宣布SOTA。

## 已冻结实施与建议的区别

本文是独立审核建议；最终部署范围以方案表/protocol/spec为准。本轮不做专门低通/blur/compression、attention定位、mask内外残差或运动区域读出。六种CF控制匹配支持面积、激活概率与随机几何；PHOTO、NOISE、donor的像素残差能量并不严格相等，源probe保存input_edit_energy/future_edit_energy，不能把支持匹配等同于能量完全匹配。本轮将全部强度档与全部控制提前冻结，未进行基于目标结果的扩展。
