## 固定条件和评价

共22次、110,000更新，完整产生66条目标AUROC。全部seed17、5000step、batch8、FP32；原G/D/N/O/Arc初始参数、40,000源片段及独立donor计划配对相同。新增skip参数在隔离RNG中初始化。每250step保存checkpoint；仅最终5000step进入性能比较。正常性增强、优化器、损失和测试流程均保持原c04，表内明确的单项改动除外。

源域只有ShanghaiTech330个正常训练视频；目标为Ped1/Ped2/Avenue测试。固定V2视频排序和逐帧标签，排除每视频前4帧。测试仅G；负PSNR视频内min-max后合并逐帧AUROC。三个目标等权平均macro AUROC。仅AUROC作为性能依据；不报告bootstrap。

报告每一候选的三个目标AUROC、三个相对B增减和macro增减。`macro_delta>0`标为整体正提升；任一目标正提升单独列出，不能将“仅单域提高”写成整体提高。全部负结果、控制及未完成项保留。单种子正提升只进入待确认名单，不声称稳定提升；本轮目标是发现候选，不是最终统计确认。历史目标反馈已用于设计，这不是盲测。

QC01/QC03不是已完成Q=0.1的重复；G25/G00不是已完成N=0.45005的重复；Tweak不是已完成T的重复。本轮不重跑已审核的T/N/Q原设置或组合。R100迁移旧PNC real正样本选择；R50为同一不足的中间强度。历史主方案／控制身份保持不变，U9和C7是作为功能候选迁移的旧控制。

## 空间控制和科学边界

S25/SR25在O的原始网格上严格同面积，最近邻缩放到随机整数矩形后贴入像素面积可能略有不同，记录实际paste面积。稀疏随机O响应不等于语义前景。M20/MR20的最终像素权重直方图一致。F9/U9为相同总opacity的空间分配比较，空mask回退为零opacity；soft mask同时用于N注意力监督。

普通skip卷积和区域加权是已知方向；候选是向固定c04迁移／调整，不能仅凭一个正数声称新方法或SOTA。G00若提高只说明该独立实现中的引导可能有害，不能证明原论文对应组件有害。

## 双卡队列和部署

用户确认前一版未部署，MoBA已释放GPU0。本轮使用物理GPU0、GPU1，各自串行执行11次独立训练；不采用DDP，不改变单个训练的batch8和5000step。22项均执行，没有截止时间、耗时准入、超时看门狗或自动减少方案。顺序只按预先冻结的队列决定，不根据本批AUROC调整。

- GPU0：B → S25 → SR25 → C7 → R50 → G25 → CM7 → R100 → S12 → S50 → G00。
- GPU1：M20 → MR20 → U9 → QC03 → C3 → M10 → F9 → QC01 → C1 → M20W → Tweak。

主要空间控制S25/SR25、M20/MR20、F9/U9及CM7/C7在同一卡运行。两个进程共享只读源域抽样计划和协议，使用独立日志、预检查、状态和候选产物目录。两卡分别验证真实CUDA前向／反向和原始c04更新一致性；两卡首个一次性源域B更新的模型、Adam和RNG摘要必须一致，才能开始正式训练。该检查不等于证明完整5000step轨迹在两卡永远一致。B仅在GPU0训练一次；GPU1方案对B的比较跨卡，报告每项物理GPU和硬件身份，后续确认时需要排查硬件影响。

两卡11次训练全部完成后，统一冻结最终5000step checkpoint与目标身份，再由原负责GPU评测其11个模型。结果保留22项、66条目标AUROC；失败明确报告，不能当作完成。每250step保存checkpoint；重运行同一启动指令会从已保存步数恢复，已完成训练和完整评测跳过。中途进程异常最坏回退至上一250step存档。数据或环境身份改变会拒绝混用产物。

按每次30分钟粗估，每卡训练约5.5小时，另加预检查与评测；双卡共享CPU、磁盘，实际耗时以日志为准。GPU被其他任务占用时只等待空闲，不停止其他进程。不会向旧方案或MoBA进程发送停止信号。
